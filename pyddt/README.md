# pyddt

The package of all the dvmdostem related python stuff...

Install from the repository root with `python -m pip install -e ./pyddt`.
After adding new console entry points, rerun this command to make them available.

Run `pyddt` or `pyddt --help` for an overview of the available commands:

- `pyddt-input`: validate, crop, and plot input NetCDF files.
- `pyddt-outspec`: list and enable output variables.
- `pyddt-param`: read, edit, and convert parameter files.
- `pyddt-runmask`: create, modify, and view run masks.
- `pyddt-swd`: set up a model working directory.
- `pyddt-qcal`: compare results with calibration targets.

Run any command with `--help` for its options, for example
`pyddt-input --help`.
